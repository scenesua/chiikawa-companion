# MOMONGA DESKTOP COMPANION

Windows 10/11 · C# · .NET 8 · WPF 프로토타입.

## 실행

최신 배포 폴더 dist-latest의 Momonga.Desktop.exe를 실행합니다. 기존 버전이 실행 중이면 더보기 또는 트레이의 종료로 끈 뒤 새 버전을 실행합니다. .NET 8 Windows Desktop Runtime이 필요합니다.
SDK 빌드: dotnet build. 검증: Momonga.Desktop.exe --self-test 및 --ui-check.
UI 검증은 obj/ui-check에 실제 WPF 화면을 저장하고 상호작용 통합 검사를 실행합니다.

## 조작

펫 우클릭: 원형 상호작용 HUD. 더보기에서 설정, 상점, 보관함, 디버그를 엽니다.
드래그로 위치 이동. 쓰다듬기와 볼 당기기는 기본적으로 우클릭 메뉴에서 고릅니다. 설정에서 직접 만지기를 켜면 머리·턱·볼 드래그로 바로 상호작용합니다.
볼 당기기와 딱밤 준비는 HUD 장난 메뉴에서 선택합니다.
설정 HUD의 연속 슬라이더: 펫·가구 크기 50–200%. Ctrl + 휠도 지원합니다. 뒤로가기·Esc·외부 영역 클릭으로 HUD를 닫습니다.
별도 집 없이 투명 가구를 바탕화면 어디든 드래그해서 놓습니다. 우클릭의 연속 슬라이더로 가구 크기를 조절하고 잠금, 회전, 회수합니다.
밥은 보관함에서 그릇에 넣고 물은 무료로 채웁니다.
방석 우클릭에서 방해금지를 켜고 펫을 가까이 놓으면 조용한 생활 모드입니다.
방해금지를 끄거나 멀어지면 해제됩니다. 조용한 모드에서도 욕구와 자율 행동은 계속됩니다.
방석·그릇을 더블클릭하거나 우클릭에서 사용하면 해당 물건으로 이동해 잠자기·식사·마시기를 합니다.
방석에 펫을 내려놓으면 먼저 앉습니다. 이후 성격과 욕구에 따라 쳐다보거나 잠들거나 떠납니다.
방석 앉기/잠자기, 식사/음수는 고정된 가구 위에 전용 캐릭터 스프라이트를 표시합니다. 방석에서는 캐릭터의 몸이 방석에 맞춰 작아지고, 떠나면 원래 크기로 돌아옵니다. 방석은 기본 가구보다 19% 넓습니다. 상호작용으로 가구의 위치·비율이 바뀌지 않습니다.
그릇 내용량은 가득 참/줄어듦/비어 있음으로 표시됩니다. 필요하면 스스로 먹고 마시고, 비어 있으면 요구합니다.
딱밤 준비는 손 모양 이미지 커서로 바뀌며 펫을 클릭하면 딱밤 반응 후 해제됩니다. 볼 당기기, 쓰다듬기, 칭찬, 찌르기, 간식, 놀이, 깨우기도 지원합니다.
가구를 쓰는 장면의 펫도 클릭, 우클릭 상호작용 메뉴, 드래그로 꺼내기가 가능합니다.
방석은 펫 크기를 따라가며 연속 슬라이더로 비율을 추가 조절합니다. 가구는 항상 펫 아래에 표시됩니다.
트레이 메뉴에서 숨기기, 다시 부르기, 종료를 사용할 수 있습니다.
숨긴 뒤 실행파일을 다시 실행해도 기존 펫을 불러옵니다. 더보기 → 캐릭터 변경에서 카테고리별 그림 그리드로 선택하며, 카테고리는 접을 수 있습니다. 캐릭터를 바꾸어도 AP·보관함·물건 배치는 유지됩니다.

## 구현

8방향 이동 스프라이트, 부드러운 단계별 커서 방향 전환, 앉기/졸기/몸단장/기지개 대기 모션.
욕구 기반 행동, 식사/물/잠/놀이, 제한된 요구와 재요청, 간식 선호, 관계/짜증, 대화 중복 방지.
캐릭터별 성격(돌아다니는 빈도 포함), 대사/스프라이트와 HUD 테마는 Content JSON에서 지정합니다.
원형 HUD, 카드형 설정, 욕구 표시, 상점/보관함/가구 배치를 연결했습니다.
문자 이모티콘 대신 AI 생성 투명 PNG 아이콘을 사용합니다.
만화 말풍선은 38ms마다 한 글자씩 나오면서 실시간으로 커집니다. 가로 최대 276 DIP를 넘으면 줄바꿈합니다.
캐릭터 TalkFrequency(0–1)로 자율 말 걸기 빈도를 조절하며 0이면 먼저 말하지 않습니다.
확인된 짧은 실제 대사의 자체 한국어 번역도 가끔 섞습니다. 출처는 Content/dialogue-sources.md에 기록했습니다.

## AP와 물가

기본 타자 1회 또는 마우스 버튼 클릭 1회마다 1 AP가 즉시 적립됩니다. 시간만 지나서는 적립되지 않습니다.
설정에서 입력당 1–3 AP를 조정할 수 있습니다. 시간당 획득 제한은 없습니다.
입력 내용, 키 코드, 대상 프로그램은 읽거나 저장하지 않습니다. 키 누름 이벤트(자동 반복 포함)와 버튼 클릭 횟수만 셉니다.
마우스 이동/휠은 AP를 주지 않습니다. 과도한 반복 적립은 초당 30회로 제한합니다.
초기 15,000 AP, 기본 식사 350 AP, 쿠키 250 AP, 공 2,000 AP. 밥그릇 메뉴에서 무료 흰밥을 바로 넣을 수 있습니다.
이전 저장의 AP 잔액은 새 물가에 맞춰 100배로 변환합니다.

## 저장과 범위

저장: %LOCALAPPDATA%/MomongaDesktopCompanion/save.json. 자동 저장, 종료 저장, 원자적 교체 및 이전 백업.
손상 저장은 원본을 백업하고 기본값으로 복구합니다. 장기 부재 시 변화는 2시간으로 제한합니다.
현재 치이카와 13명, 리락쿠마 2명, 마이멜로디·쿠로미를 선택할 수 있습니다. 서로 다른 DPI의 여러 모니터는 실기 검증이 추가로 필요합니다.
AI 이미지 원본과 생성 프롬프트는 Assets에 있습니다. 공식 원본 아트가 아닙니다.

## 식사·상호작용 추가

직접 만지기를 끈 상태의 짧은 클릭은 일상 대화이며 이동 드래그는 그대로 가능합니다.
흰밥·후리카게·라멘은 젓가락, 카레·케이크·푸딩은 숟가락, 견과류·과일·쿠키·도라야끼·사탕은 앞발로 먹습니다.
물은 식사와 별도 프레임으로 물그릇에서 마십니다. 먹는 중에는 그릇에 놓인 숟가락을 숨깁니다.
식사는 배고픔이 45 이상일 때 자율적으로 시작하며, 배고픔이 5까지 내려가면 멈추고 남은 양을 저장합니다. 온라인 배고픔은 분당 0.2 증가해 충분히 먹은 뒤 약 3시간 20분 간격으로 다음 식사가 필요합니다.
밥은 한 그릇에 한 종류만 담고, 남긴 밥은 기존 절반 그림으로 표시합니다. 회수한 그릇의 남은 밥도 양을 보존해 보관함으로 돌려줍니다.
공은 굴리는 놀이, 인형은 안는 놀이를 사용하고 만족하거나 우클릭하면 끝납니다. 방석·빈백·둥지는 다른 그림과 휴식 회복량을 사용합니다.
캐릭터·가구 생성은 내장 image_gen 도구를 사용했습니다. 프롬프트와 원본 경로: Assets/meal-generation.json, Assets/additions-generation.json, Assets/drinking-generation.json.
