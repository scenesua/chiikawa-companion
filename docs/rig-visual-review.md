# 얼룩 수정 이미지 리뷰 — 2026-10-03

이번 검사는 새 실행파일 대신 현재 소스를 메모리에서 컴파일해 WPF로 그린 이미지다.

## 수정하고 재확인한 문제

- 투명 영역이 귀·몸·피부를 덮어 지우던 합성 오류를 수정했다.
- 표정을 합친 뒤 전신 그림을 다시 분리하면서 생기던 얼굴 얼룩을 제거했다.
- 볼 변형에서 겹치는 삼각형 대신 역방향 샘플링을 사용해 줄무늬를 제거했다.
- 볼터치에 털 외곽선이 섞이지 않게 했고, 눈·코·입은 고정해서 합성한다.
- 리락쿠마 입 주변과 배, 데카츠요 흰 얼굴, 오데 눈·부리 경계를 보정했다.
- 추가 이미지 리뷰에서 발견한 산리오 얼굴 경계의 작은 흰 조각도 다시 수정했다.
  모자와 피부를 픽셀 색만으로 나누던 경계 대신 이어진 얼굴 영역을 사용한다.
- 테스트 시트 가장자리에서 당긴 볼이 잘리던 배치도 넓혔다.

## 검사 범위

17캐릭터의 일반 프레임 1,312개를 분리·재합성해 원본 픽셀과 비교한다.
양쪽 볼 각각 8방향, 모몽가 놓기 후 복원, 흰밥 식사와 물 마시기 샘플을 그려 검토한다.
투명 구멍, 잘못된 알파 색상, 하체 변형, 방향이 맞지 않는 표정 적용도 검사한다.

## 완료로 간주하지 않은 범위

모든 방향·가구 자세의 해부학적 레이어 배치가 수작업으로 확정된 것은 아니다.
모든 음식 조합과 가구 상호작용의 실제 앱 동작, macOS 네이티브 렌더링은 이번 검사에 포함되지 않는다.
기존 원화 디자인을 새로 그린 작업도 아니다. 테스트 통과를 전체 기능 완료로 해석하면 안 된다.
이번에는 빌드·패키징·릴리즈를 하지 않았다.
