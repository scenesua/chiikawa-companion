# 모몽가 대사 출처

대부분은 앱용 창작 대사입니다. 아래는 확인한 일본어 대사의 짧은 자체 한국어 번역이며 공식 한국어 번역과 다를 수 있습니다.

- 「イーヤーヤダヤダ」 → 싫어! 싫다고! (27/68/104화)
- 「しょっぱみがあって…うまッ」 → 소금기가 있어서… 맛있어! (69화)
- 「ついにやったゾ!!」 → 드디어 해냈다!! (25화)

출처: https://times.abema.tv/articles/-/10154690

- 「おもいっっっっきりかわいこぶってやる…！」 → 한껏 귀여운 척해 주겠어…!

출처: https://www.anime-chiikawa.jp/info.html?k=/entry/0915

인용은 창작 대사와 같은 후보 목록에서 가끔 선택됩니다.

## 추가 캐릭터

우사기 발성 확인: https://chiikawa.hatenablog.jp/entry/2021/12/03/143810 ; https://anna-movies.com/chiikawa/phrase/usagi-language/
`ウラ / ヤハ / プルャ / フゥン / ハァ?`의 한국어 표기와 짧은 변형을 사용합니다. 팬 정리는 발성 확인용이며 공식 대본으로 표시하지 않습니다.
치이카와는 `응… / 아… / 와…` 같은 짧은 반응만 사용합니다. 아노코·카니·장수풍뎅이·리락쿠마·코리락쿠마는 `…`만 표시합니다.
하치와레·시사·랏코·오데의 추가 한국어 문장은 성격을 반영한 자체 창작이며 원작 직접 인용으로 표시하지 않습니다. 쿠리만쥬는 주로 `… / 하아…` 같은 짧은 반응만 사용합니다.

식사·간식·물·칭찬·달래기·거절·깨우기 반응도 앱용 한국어 창작이며 실제 원작 인용으로 표시하지 않습니다.
마이멜로디와 쿠로미의 디자인·성격 참고는 산리오 공식 소개입니다:
https://www.sanrio.co.jp/characters/mymelody/
https://www.sanrio.co.jp/characters/kuromi/
두 캐릭터의 한국어 대사는 공식 애니메이션 대본 인용이 아닌 성격에 맞춘 앱용 창작입니다.
