# 모몽가 대사 출처

대부분은 앱용 창작 대사입니다. 아래는 확인한 일본어 대사의 짧은 자체 한국어 번역이며 공식 한국어 번역과 다를 수 있습니다.

- 「イーヤーヤダヤダ」 → 싫어! 싫다고! (27/68/104화)
- 「しょっぱみがあって…うまッ」 → 소금기가 있어서… 맛있어! (69화)
- 「ついにやったゾ!!」 → 드디어 해냈다!! (25화)

출처: https://times.abema.tv/articles/-/10154690

- 「おもいっっっっきりかわいこぶってやる…！」 → 한껏 귀여운 척해 주겠어…!

출처: https://www.anime-chiikawa.jp/info.html?k=/entry/0915

인용은 창작 대사와 같은 후보 목록에서 가끔 선택됩니다.

## 추가 캐릭터

우사기 발성 확인: https://chiikawa.hatenablog.jp/entry/2021/12/03/143810 ; https://anna-movies.com/chiikawa/phrase/usagi-language/
`ウラ / ヤハ / プルャ / フゥン / ハァ?`의 한국어 표기와 짧은 변형을 사용합니다. 팬 정리는 발성 확인용이며 공식 대본으로 표시하지 않습니다.
치이카와는 `응… / 아… / 와…` 같은 짧은 반응만 사용합니다. 아노코·카니·장수풍뎅이·리락쿠마·코리락쿠마는 `…`만 표시합니다.
하치와레·시사·랏코·오데의 추가 한국어 문장은 성격을 반영한 자체 창작이며 원작 직접 인용으로 표시하지 않습니다. 쿠리만쥬는 주로 `… / 하아…` 같은 짧은 반응만 사용합니다.

식사·간식·물·칭찬·달래기·거절·깨우기 반응도 앱용 한국어 창작이며 실제 원작 인용으로 표시하지 않습니다.

## 오데 말투 재확인 (2026-10-02)

감옥 편의 원작 만화와 편지를 확인했습니다. 오데는 비언어 캐릭터가 아닙니다. 1인칭 `オデ`, 소박한 문장, 말 사이의 쉼, 일본어 어미 `〜ど`가 특징이며 모든 문장을 자기 이름과 단정형으로 끝내는 방식으로 제한하지 않습니다. 동료에게 말을 걸거나 상황을 설명하고 부탁하며, 편지에서도 문장으로 소식을 전합니다. 한국어 앱 대사는 원작의 `〜ど` 느낌을 살린 `~다도…` 어미와 짧게 끊는 문장을 섞어 자체 번안합니다. `~다도`는 공식 한국어 정발·자막에서 확인한 어미가 아니라 앱용 표현이며, 모든 문장에 붙이지 않습니다. 일반 상담식 질문이나 유창한 장문은 넣지 않습니다.

- 원작 2021-10-29: `オデといっしょに食べよう` → `오데랑 같이 먹자.` (Hungry·IdleTalk에 사용한 자체 번역)

- 원작 2021-11-11: `大丈夫` → `괜찮아…` (SootheReaction의 짧은 자체 번역)
  https://x.com/ngnchiikawa/status/1458793281580527616
- 원작 2021-11-18의 편지: 1인칭·문장 구사·`〜ど` 어미 확인용이며 편지 전문을 앱 대사로 옮기지 않았습니다.
  https://x.com/ngnchiikawa/status/1461025123931066369

공식 X 직접 접근이 차단되어 원작 게시물 ID가 함께 명시된 아래 팬 페이지의 만화 이미지를 대조해 읽었습니다. 팬 사이트를 공식 자료로 표시하지 않습니다.

위 두 짧은 자체 번역을 제외한 오데 대사는 앱 상황에 맞춘 창작입니다. 말을 할 수 있다는 점과 자주 말하는 성격은 구분하며, 말 걸기 빈도는 차분한 성격에 맞게 유지합니다.
마이멜로디와 쿠로미의 디자인·성격 참고는 산리오 공식 소개입니다:
https://www.sanrio.co.jp/characters/mymelody/
https://www.sanrio.co.jp/characters/kuromi/
두 캐릭터의 한국어 대사는 공식 애니메이션 대본 인용이 아닌 성격에 맞춘 앱용 창작입니다.

## 데카츠요 대사 추가 (2026-10-02)

공식 X 게시물의 원작 만화 이미지를 직접 읽고, 데카츠요가 문장으로 대화하며 조심스럽게 말리거나 상대의 반응을 걱정하는 말투를 확인했습니다. 오데의 1인칭·어미를 데카츠요에게 적용하지 않습니다. 낮은 말 걸기 빈도와 짧은 쉼은 유지하고, 식사·음수·간식·인사·쓰다듬기·딱밤·칭찬·달래기·거절·잠과 일상 대화의 19개 상황에 총 40개 후보를 제공합니다.

- 원작 2022-12-07의 `やめなよ…` → `그만해…` (Annoyed, 자체 한국어 번역)
  https://x.com/ngnchiikawa/status/1600295490696151041
- 원작 2024-08-12의 `怒んないでよォ…` → `화내지 마아…` (RefuseReaction, 자체 한국어 번역)
  https://x.com/ngnchiikawa/status/1822962651661836474

두 짧은 자체 번역 이외의 대사는 원작 말투를 참고한 앱용 창작이며, 공식 한국어 번역이나 원작 직접 인용으로 표시하지 않습니다. 게시물 탐색에는 아래 비공식 등장 회차 목록을 사용했고, 대사는 목록 제목이 아닌 원작 이미지와 대조했습니다.
